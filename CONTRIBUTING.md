# Contributing to DRAForge

<!-- SPDX-License-Identifier: Apache-2.0 -->

Welcome! We are excited that you want to contribute to DRAForge.

## Code of Conduct

Please read and follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## How Can I Contribute?

1. **Reporting Bugs**: Check existing issues first. Use the bug report template when filing.
2. **Feature Requests**: Discuss features in Issues or Discussions before implementing.
3. **Pull Requests**:
   - Create a feature branch from `main`.
   - Ensure all tests pass.
   - Use Conventional Commits.
   - Add unit/integration tests for new code.
