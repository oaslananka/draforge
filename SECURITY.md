# Security Policy

<!-- SPDX-License-Identifier: Apache-2.0 -->

## Supported Versions

Only the latest release is actively supported with security updates.

| Version | Supported |
| ------- | --------- |
| v0.1.x  | Yes       |
| < v0.1  | No        |

## Reporting a Vulnerability

If you discover a security vulnerability, please email `oaslananka@gmail.com` with details. Do not open a public issue. We aim to respond within 48 hours and coordinate a public advisory if necessary.
