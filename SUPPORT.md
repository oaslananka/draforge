# Support for DRAForge

<!-- SPDX-License-Identifier: Apache-2.0 -->

Here is how you can get help with DRAForge:

1. **Documentation**: Start with the `docs/` directory:
   - [Contributing Guide](CONTRIBUTING.md) — setup, testing, PR expectations
   - [Release Process](docs/release.md) — release flow and artifacts
   - [Dashboard Guide](docs/dashboard.md) — web dashboard usage
   - [Simulator Scenarios](docs/simulator-scenarios.md) — scenario authoring
   - [Kubernetes DRA Compatibility](docs/compatibility/kubernetes-dra.md) — support matrix
   - [Maintainer Checklist](docs/maintainer-checklist.md) — internal processes

2. **GitHub Issues**: Search existing issues or open a new one for bugs and feature
   requests using the provided templates.

3. **Discussions**: Use [GitHub Discussions](https://github.com/oaslananka/draforge/discussions)
   for Q&A, ideas, and general architectural chat.

4. **Security Issues**: Do **not** open a public issue. Email `oaslananka@gmail.com`
   directly. See [SECURITY.md](SECURITY.md) for details.
