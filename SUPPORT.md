# Support for DRAForge

<!-- SPDX-License-Identifier: Apache-2.0 -->

Here is how you can get help with DRAForge:

1. **Documentation**: Read the official documentation inside the `docs/` folder.
2. **GitHub Issues**: Search for existing issues or open a new one for bugs.
3. **Discussions**: Use GitHub Discussions for Q&A, ideas, and general architectural chat.
4. **Email**: For security issues, contact `oaslananka@gmail.com` directly.
